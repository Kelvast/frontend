# MMO Client<br><br>A browser-based 3D MMO client built with **Next.js**, **Babylon.js**, and **Zustand**.<br><br>## Overview<br><br>Players move around a tile-based world, interact with others in real-time, and progress through various skills and quests. The project is currently in an active development phase with core systems for networking, rendering, movement, and skills established.<br><br>## Key Features<br><br>* **High-Performance 3D Rendering**: Powered by Babylon.js with a custom chunk-based world system.<br>* **Skill-Based Progression**: 23 unique skills (Mining, Woodcutting, Agility, etc.) with level/XP tracking.<br>* **Paced Movement System**: Multiple movement states (Sneak, Walk, Run, Mounted) with Agility-scaled speeds.<br>* **Binary Wire Protocol**: Optimized 8-byte numeric tuples for high-frequency world actions.<br>* **Secure Communication**: Per-session XOR encryption with HMAC-2B signature validation.<br>* **Real-time Multiplayer**: Bidirectional sync via WebSockets.<br>* **State Management**: Lightweight game state handled by Zustand.<br><br>## Getting Started<br><br>### Prerequisites<br><br>* Node.js (Latest LTS recommended)<br>* npm or yarn<br><br>### Installation<br><br>1. Clone the repository<br>2. Install dependencies:<br>   ```bash<br>   npm install<br>   ```<br>3. Configure environment variables in `.env`.<br><br>### Development<br><br>Run the development server:<br>```bash<br>npm run dev<br>```<br><br>## Architecture Details<br><br>For a deep dive into the project's architecture, including coordinate systems, chunk loading strategies, and the detailed network protocol, please see [CONTEXT.md](./CONTEXT.md).<br><br>## License<br><br>[MIT](./LICENSE)
